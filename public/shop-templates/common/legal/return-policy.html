Easy Returns & RefundsWe want you to be satisfied. If not, easy return and refund process.
1. Return Eligibility

1.1 Time Window: Returns accepted within 24 hours of delivery for most products. Food, perishable items must be reported within 2 hours.

1.2 Condition: Products must be unused, unwashed, in original packaging with tags (if applicable).

1.3 Proof: Please provide photos/videos of issue for faster processing.

1.4 Non-returnable: Perishable goods (fruits, vegetables, dairy, bakery, cooked food) once accepted, cannot be returned unless quality issue at delivery. Custom/made-to-order items, medicines, intimate products non-returnable.

2. Reasons for Return

✅ Wrong product delivered

✅ Damaged, expired, or spoiled product

✅ Quality issue (rotten fruits, stale bakery, etc)

✅ Product not as described

✅ Missing items in order

✅ Size/fit issue (for clothes, footwear - within 24 hours, tags intact)

❌ Changed mind after delivery (for perishables) - not eligible

❌ Product used or washed

3. How to Request Return

Step 1: Go to Profile → My Orders → Select order → Request Return

Step 2: Select reason, add photos, description

Step 3: Shop will review within 2 hours and approve/reject

Step 4: If approved, pickup will be arranged or you can visit shop

Step 5: Refund processed after product received and checked

Or contact support: Profile → Help → Chat Support or call +91 9876543210

4. Refund Process

4.1 Refund Methods: Refund to original payment method - UPI, wallet, bank, or as store credit.

4.2 Timeline:

• Wallet: Instant to 2 hours

• UPI: 2-24 hours

• Bank transfer: 2-5 working days

• COD orders: Refund as wallet credit or bank transfer (provide bank details)

4.3 Partial Refund: If only part of order has issue, partial refund for that product.

4.4 Shipping Charges: Delivery charges non-refundable unless shop's fault.

5. Exchange Policy

5.1 Exchange: For size/fit issues in clothes, footwear, you can exchange for different size if available.

5.2 Process: Same as return - request exchange in app, select new size.

5.3 Price Difference: If new product price different, difference will be charged/refunded.

6. Damaged/Defective Products

6.1 At Delivery: Please check product at delivery. If damaged, refuse or inform delivery boy immediately and take photo.

6.2 After Delivery: If you find damage later, report within 2 hours for perishables, 24 hours for others with photos.

6.3 Shop Responsibility: Shop is responsible for product quality. SamanLive will mediate if needed.

6.4 Proof Required: Photos/videos of damaged product, packaging, bill.

7. Order Cancellation

7.1 Before Confirmation: You can cancel anytime before shop confirms order - full refund.

7.2 After Confirmation but Before Out for Delivery: Cancellation allowed, but may incur 10% charge if shop already started preparing (for food, bakery, custom orders).

7.3 After Out for Delivery: Cannot cancel. You can refuse delivery if product has issue, then request return.

7.4 Shop Cancellation: If shop cancels, full refund including delivery charges.

8. Failed Delivery & Returns

8.1 Customer Not Available: If delivery fails because customer not available, not answering phone, wrong address, order will be returned to shop.

8.2 Re-delivery: Re-delivery may be attempted once. If fails again, order cancelled. Delivery charge non-refundable, product amount refunded.

8.3 Perishable: For perishable items, if delivery fails, product may be discarded and only partial refund if applicable.

9. Dispute Resolution

9.1 Contact Shop First: For any issue, contact shop via chat/call. Most issues resolved directly.

9.2 SamanLive Support: If not resolved with shop, contact SamanLive support - we will mediate.

9.3 Evidence: Keep photos, videos, bill, chat with shop as evidence.

9.4 Timeline: Disputes should be raised within 24 hours of delivery for faster resolution.

9.5 Final Decision: SamanLive's decision in disputes will be final and binding.
